🔖 Bookmark Manager – Nastavenia rozšírenia

V prehliadači otvor svoj súbor index.html normálne cez Súbor → Otvoriť, skopíruj presnú adresu z panela s adresou a vlož ju sem.
Uložené ✓

Dôležité: povoľ prístup k súborom

  1. Otvor chrome://extensions (alebo edge://extensions).
  2. Nájdi „Bookmark Manager – Uložiť stránku" a klikni na „Podrobnosti".
  3. Zapni prepínač „Povoliť prístup k adresám URL súborov" / „Allow access to file URLs".
Bez tohto kroku rozšírenie nedokáže otvoriť/prepnúť na lokálny file:// súbor.
